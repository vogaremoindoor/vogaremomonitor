# vogaremomonitor

Página de teste para conectar ao monitor Concept2 PM5 via Bluetooth Low Energy (Web Bluetooth) e exibir dados do treino em tempo real.

- iPhone: abrir no navegador **Bluefy**
- Android / desktop: Chrome ou Edge

No PM5, toque em **Connect** antes de conectar. O PM5 aceita apenas uma conexão BLE por vez.
